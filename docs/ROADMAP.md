# FindIt roadmap

1. Replace localStorage mutations with authenticated server actions and Supabase repositories.
2. Add Supabase Auth and role-aware RLS for students, staff, and administrators.
3. Split public item fields from private ownership evidence and staff-only inventory data.
4. Move photos to protected Supabase Storage and add upload moderation.
5. Add real-time updates for claims, moderation, inventory, and notifications.
6. Add Resend-backed email delivery with retries and notification preferences.
7. Add school tenancy, pickup scheduling, QR inventory labels, audit exports, and end-to-end browser tests.
